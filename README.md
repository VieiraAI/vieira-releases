# Vieira Dialogue — Releases

Official signed builds of [Vieira Dialogue](https://www.vieiraai.com) — the desktop app where AI teammates help you build products.

**[⬇ Download the latest release](https://github.com/VieiraAI/vieira-releases/releases/latest)**

- **macOS (Apple Silicon):** `Vieira.Dialogue_<version>_aarch64.dmg`
- **macOS (Intel):** `Vieira.Dialogue_<version>_x64.dmg`

Every build is signed with our Apple Developer ID and notarized by Apple. Open the DMG and drag Vieira Dialogue to Applications.

Source code lives in a private repository; this repo hosts release artifacts and the auto-update feed.
